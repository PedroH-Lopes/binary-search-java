# Binary Search in Java

This project implement the Binary Search algorithm in Java.
This was made as part of my studies about algorithms.

## Requirements
- Java JDK 8+

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/PedroH-Lopes/binary-search-java.git
```

2. Compile the project:
```bash
javac -d out src/main/java/br/com/pedrohlopes/*.java
```

3. Run the application:
```bash
java -cp out br.com.pedrohlopes.Main
```
